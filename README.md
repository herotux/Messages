# Herotux Messages

[![Android CI](https://github.com/herotux/Messages/actions/workflows/build-apk.yml/badge.svg)](https://github.com/herotux/Messages/actions/workflows/build-apk.yml)

Herotux Messages is a lightweight Android SMS and MMS messaging application focused on a clean, fast, and privacy-friendly messaging experience.

## Features

- 📱 **SMS & MMS** — Send and receive SMS and MMS messages, including group conversations, photos, emojis, and multimedia content.
- 👥 **Group Conversations** — Manage conversations with multiple participants.
- 🔍 **Message Search** — Quickly search conversations and message content.
- 🚫 **Message Blocking** — Block unwanted senders and manage blocked messages.
- 💾 **SMS Backup & Restore** — Export and import messages when moving between devices.
- 📁 **Conversation Folders** — Organize conversations into custom folders for easier access.
- 🏷️ **Conversation Labels** — Show the folder label directly on conversation cards and keep conversations organized.
- 💳 **Iranian Bank Accounts** — Save and manage Iranian bank account information, including card numbers and IBANs, with bank recognition and bank logos.
- 📷 **Live Bank Card Scanner** — Scan Iranian bank cards using the camera and automatically detect the card number and bank.
- 📋 **Card Details Picker** — Insert saved bank account details into conversations with formatted card and IBAN information.
- 🗓️ **Persian Calendar** — Support for Persian/Jalali dates in the messaging experience.
- 🇮🇷 **Persian Language & RTL** — Persian UI support with right-to-left layout and Persian typography.
- 🎨 **Material Design** — Modern Material-based interface with light and dark themes.
- ⚙️ **Customizable Settings** — Configure the messaging experience and application behavior.
- 🔒 **Privacy Controls** — Control sensitive message content and what is shown on the lock screen.
- ⚡ **Lightweight & Fast** — Designed for responsive everyday messaging without unnecessary complexity.

## Build

The project uses GitHub Actions to build the Android APKs automatically.
